# 21 · ความถูกต้องของตัวเลข และการยกเลิกเอกสาร

> โจทย์จากฝ่ายบัญชี (ตุลาคม 2569): *"เรื่องบัญชีเป็นเรื่องละเอียดอ่อน เรื่องตัวเลขที่พลาดไม่ได้ จัดการให้ครบ"*
> เอกสารนี้บอกว่าระบบใน `webapp/` คุมตัวเลขอย่างไร ยกเลิกเอกสารแล้วเกิดอะไรขึ้น
> และข้อผิดพลาดที่ตรวจเจอในรอบนี้ แก้แล้วอย่างไร พร้อมชื่อชุดทดสอบที่พิสูจน์ไว้

## 1. หลักที่ระบบยึดทุกบรรทัด

| หลัก | ทำอย่างไร |
|---|---|
| เงินเป็นจำนวนเต็มเสมอ | เก็บเป็นจำนวนเต็มคูณ 10,000 ไม่มีทศนิยมลอยตัวในยอดเงิน · แปลงข้อความเป็นเงินด้วยการแยกเลขจำนวนเต็มกับทศนิยมเอง ไม่ผ่าน `parseFloat` |
| คูณแล้วหาร ไม่หารแล้วคูณ | สัดส่วนทุกแบบ (ฐานภาษีหัก ณ ที่จ่ายตามยอดที่รับ/จ่าย ต้นทุนสินค้าที่รับคืน) ใช้ `mulDiv(a, b, c)` จำนวนเต็มล้วน ปัดครึ่งขึ้น ผลคูณที่ใหญ่เกินช่วงปลอดภัยใช้ BigInt |
| ปัดที่จุดเดียวกับเอกสารจริง | ฐานภาษีหัก ณ ที่จ่ายปัดเป็นสตางค์ก่อน แล้วค่อยคิดภาษีจากฐานที่ปัดแล้ว — ตรงกับตัวเลขที่พิมพ์บน 50 ทวิ |
| ครั้งสุดท้ายรับส่วนที่เหลือ | แบ่งรับหรือแบ่งจ่ายหลายครั้ง ครั้งสุดท้ายใช้ฐานที่เหลือทั้งหมด ผลรวมฐานทุกครั้งจึงเท่าฐานเต็มพอดี · ขายสินค้าชิ้นสุดท้ายรับมูลค่าคงเหลือทั้งหมด ของหมดคลังแล้วมูลค่าเป็นศูนย์พอดี |
| จำนวนสินค้าละเอียด 3 ตำแหน่ง | บวกลบแล้วปัดทุกครั้ง 0.1 + 0.2 − 0.3 เป็นศูนย์จริง |
| ทำเป็นชุดเดียว | ทุกคำสั่งที่เขียนข้อมูลถ้าล้มกลางทาง ข้อมูลกลับเหมือนก่อนเริ่มทั้งหมด **รวมถึงเลขที่เอกสารที่จองไปแล้ว** ทะเบียนจึงไม่มีเลขขาดช่วงจากคำสั่งที่ล้ม |
| เลขที่ไม่ซ้ำ | ชนิดเอกสารที่ใช้คำนำหน้าเดียวกันนับด้วยตัวนับเดียวกัน (ใบสำคัญทั่วไปกับใบปรับปรุงใช้ JV ร่วมกัน) และตรวจซ้ำกับใบที่มีอยู่ก่อนออกเลขทุกครั้ง |
| ไม่ลบ ไม่แก้ | ใบสำคัญที่ลงแล้วแก้ไม่ได้ (พ.ร.บ.การบัญชี ม.20) · ยกเลิกเอกสาร = กลับรายการ ณ วันที่เดิม เลขที่เดิมยังอยู่และขึ้นว่า "ยกเลิก" |

## 2. ยกเลิกเอกสาร — กดที่ตัวเอกสาร ระบบตามแก้ให้ครบในครั้งเดียว

ใบสำคัญที่เกิดจากเอกสาร **กลับรายการที่ใบสำคัญตรง ๆ ไม่ได้อีกต่อไป**
เพราะถ้ากลับที่ใบสำคัญ บัญชีแยกประเภทจะเป็นศูนย์ แต่ลูกหนี้รายตัว สต๊อก ทะเบียนภาษี และ 50 ทวิ ยังนับเอกสารใบนั้นอยู่
หน้าใบสำคัญจะมีปุ่ม "ไปที่เอกสาร" แทน

| ยกเลิก | ระบบทำให้ |
|---|---|
| ใบกำกับภาษี | กลับรายการขายและต้นทุนขาย · คืนสินค้าเข้าคลังด้วยต้นทุนเดิม · ทะเบียนภาษีขายแสดง "ยกเลิก" ยอดศูนย์ · ใบสั่งขายที่แปลงมากลับไปรอออกใบกำกับ |
| ใบเสร็จรับเงิน | ยอดค้างของใบกำกับกลับมา · บรรทัดสเตทเมนต์ธนาคารที่จับคู่ไว้กลับไปรอกระทบยอด |
| ใบลดหนี้ / ใบเพิ่มหนี้ | ยอดค้างและมูลค่าที่ลดได้ของใบกำกับกลับมา · ภาษีขายของใบนั้นเป็น "ยกเลิก" · ของที่รับคืนออกจากคลัง |
| คืนเงินลูกค้า | เครดิตของลูกค้ากลับมา |
| ตั้งหนี้ผู้ขาย | ทะเบียนภาษีซื้อ "ยกเลิก" · ของที่รับเข้าคลังตอนตั้งหนี้ออกจากคลัง · ถ้าตั้งหนี้จากใบรับสินค้า ใบรับสินค้ากลับไปรอใบกำกับ · ใบสั่งซื้อที่แปลงมากลับไปรอ |
| ใบสำคัญจ่าย | ยอดค้างของตั้งหนี้กลับมา · ยกเลิก 50 ทวิ และตัดออกจากแบบ ภ.ง.ด. · ใบเตรียมจ่ายบันทึกว่ารายการนั้นถูกยกเลิก |
| ค่าใช้จ่าย | ยกเลิก 50 ทวิ ที่ออกอัตโนมัติ · ภาษีซื้อ "ยกเลิก" |
| ใบรับสินค้า | นำของออกจากคลัง · ใบสั่งซื้อกลับมาค้างรับเฉพาะจำนวนของใบนั้น |
| งวดค่าเสื่อมราคา | คืนค่าเสื่อมสะสมทางบัญชีและทางภาษีของทรัพย์สินทุกตัว (ยกเลิกได้จากงวดล่าสุดย้อนกลับมา) |
| งวดเงินเดือน | ตัดออกจาก ภ.ง.ด.1 · ทำเงินเดือนงวดนั้นใหม่ได้ |

**ระบบไม่ยอมให้ยกเลิก และบอกวิธีที่ถูกแทน เมื่อ**

- ยังมีเอกสารอ้างถึง (ใบกำกับที่มีใบเสร็จ ใบลดหนี้ อยู่ในใบวางบิลที่เปิดอยู่ · ตั้งหนี้ที่จ่ายแล้วหรืออยู่ในใบเตรียมจ่าย · ใบลดหนี้ที่คืนเงินลูกค้าไปแล้ว) → ยกเลิกเอกสารที่อ้างถึงก่อน
- งวดปิดแล้ว → ใบกำกับ: ออกใบลดหนี้ในงวดปัจจุบัน (ม.86/10) · อื่น ๆ: บันทึกปรับปรุงในงวดปัจจุบัน
- ยื่นแบบ ภ.พ.30 หรือ ภ.ง.ด. ที่มีเอกสารนี้ไปแล้ว → ออกใบลดหนี้ หรือยื่นแบบเพิ่มเติมแล้วปรับปรุง
- ของที่รับเข้ามาขายออกไปแล้ว ดึงกลับออกจากคลังไม่ได้ → ขอใบลดหนี้จากผู้ขาย

ทุกครั้งต้องระบุเหตุผลอย่างน้อย 5 ตัวอักษร และก่อนยืนยันระบบแสดงรายการสิ่งที่จะเกิดขึ้นให้อ่านก่อน

## 4. ระบบตรวจอะไรให้บ้าง

- **ก่อนปิดงวด (บล็อกถ้าไม่ผ่าน):** ลูกหนี้รายตัวรวม = บัญชีคุมลูกหนี้ · เจ้าหนี้รายตัวรวม = บัญชีคุมเจ้าหนี้ · ใบรับสินค้าที่รอตั้งหนี้ = บัญชีพักรับสินค้า ·
  ทะเบียนภาษีขาย/ซื้อ = ที่ลงบัญชีจากเอกสาร · บัญชีพักเป็นศูนย์ · เดบิตรวม = เครดิตรวม · สินทรัพย์ = หนี้สิน + ส่วนของผู้ถือหุ้น · ตั้งค่าเสื่อม · ยื่น ภ.พ.30
- **เจาะดูตัวเลข:** คลิกบรรทัดใดก็ได้ในงบทดลอง งบแสดงฐานะการเงิน งบกำไรขาดทุน และอายุลูกหนี้/เจ้าหนี้
  แผงด้านขวาแสดงรายการที่ประกอบเป็นยอด แล้ว **ตรวจทุกครั้งว่าผลรวมเท่ากับตัวเลขที่คลิกพอดี** (ชุดทดสอบหน้าจอ [25] คลิกครบทุกจุด)
- **ยอดรวมท้ายตาราง** ไม่นับเอกสารที่ยกเลิก และตามตัวกรองสถานะที่เลือก

## 5. ยังเปิดอยู่ / ต้องยืนยัน

1. **อัตรา e-Withholding Tax 1%** สำหรับค่าโฆษณา วิชาชีพอิสระ และรับเหมา (2569–2570) ใส่ไว้ตามมาตรการลดอัตรา
   ผ่านระบบ e-WHT — ฝ่ายบัญชีควรยืนยันกับประกาศฉบับล่าสุด ตารางอัตราเป็นข้อมูล แก้ได้โดยไม่ต้องแก้ตรรกะ
2. **ภาษีที่ชำระเกินยกไปเดือนถัดไป** ยังค้างอยู่ในบัญชีภาษีรอขอคืน ระบบยังไม่หักกับภาษีที่ต้องชำระเดือนถัดไปให้อัตโนมัติ
3. **ใบคืนเงินลูกค้า** ยังไม่มีแบบฟอร์มพิมพ์ (ดูได้ในหน้าใบกำกับและพิมพ์ใบสำคัญได้)
4. **ภาษีหัก ณ ที่จ่ายค้างนำส่ง** ยังไม่อยู่ในรายการกระทบยอดก่อนปิดงวด เพราะยอดยกมาจากระบบเดิมไม่มีรายการรายตัว
   จะทำให้ปิดงวดไม่ได้ทุกบริษัทที่ย้ายมา — ควรทำพร้อมการนำเข้ารายการค้างนำส่งรายตัว
