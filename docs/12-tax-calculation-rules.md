# 12 — กฎการคำนวณภาษี (สเปกสำหรับนักพัฒนา)

เอกสารนี้คือข้อกำหนดระดับที่เขียนโค้ดตามได้ทันที ทุกอัตราที่ปรากฏต้อง **อ่านจากตาราง**
(`tax_rate`, `income_tax_bracket`, `sso_rate`, `tax_depreciation_rate`) โดยใช้ **วันที่ของเอกสาร**
ตัวเลขในเอกสารนี้แสดงไว้เพื่อให้เข้าใจและใช้เขียน test เท่านั้น

---

## 1. ภาษีมูลค่าเพิ่ม

### 1.1 ลำดับการคำนวณในเอกสาร (สำคัญ — ป้องกันผลต่างเศษสตางค์)

```
สำหรับแต่ละบรรทัด:
  line_amount = ROUND(quantity × unit_price, 2) − discount_amount

จัดกลุ่มบรรทัดตาม vat_treatment:
  vat_base        = Σ line_amount ของบรรทัด standard
  vat_zero_base   = Σ line_amount ของบรรทัด zero_rated
  vat_exempt_base = Σ line_amount ของบรรทัด exempt

ส่วนลดท้ายบิล (ถ้ามี) → ปันส่วนตามสัดส่วนมูลค่าของแต่ละกลุ่มก่อน แล้วปัดที่กลุ่ม

  vat_amount = ROUND(vat_base × rate ÷ 100, 2)      ← ★ ปัดครั้งเดียวที่ระดับเอกสาร
  grand_total = vat_base + vat_zero_base + vat_exempt_base + vat_amount
```

**ห้าม** คำนวณ VAT ทีละบรรทัดแล้วบวกกัน — จะได้ผลต่างจากใบกำกับที่คู่ค้าออก

### 1.2 ราคารวมภาษี (VAT-inclusive)
```
vat_base   = ROUND(inclusive_amount × 100 ÷ (100 + rate), 2)
vat_amount = inclusive_amount − vat_base
```
ต้องคำนวณแบบนี้เสมอ ไม่ใช่ `inclusive × 7/107` แยกกัน (ผลต่างเกิดเมื่อปัดเศษ)

### 1.3 จุดความรับผิดในการเสียภาษี (Tax Point)

| ธุรกรรม | VAT เกิดเมื่อ |
|---------|--------------|
| ขายสินค้า | ส่งมอบสินค้า (หรือโอนกรรมสิทธิ์/รับชำระ/ออกใบกำกับ แล้วแต่อย่างใดเกิดก่อน) |
| ให้บริการ | **ได้รับชำระราคา** (หรือออกใบกำกับ/ใช้บริการ แล้วแต่อย่างใดเกิดก่อน) |
| เงินมัดจำ/เงินรับล่วงหน้าค่าบริการ | **วันรับเงิน** → ต้องออกใบกำกับภาษีทันที |
| ขายผ่อนชำระ/ให้เช่าซื้อ | ตามงวดที่ถึงกำหนดชำระ |
| นำเข้าสินค้า | วันชำระอากรขาเข้า |
| ส่งออก | วันผ่านพิธีการศุลกากร |

**ผลต่อการออกแบบ:** ธุรกิจบริการต้องใช้ `deferred_output_vat` (2142) ตอนตั้งหนี้
แล้วโอนเข้า `output_vat` (2141) ตอนรับเงิน — ระบบต้องรองรับทั้งสองแบบตามประเภทธุรกิจ

### 1.4 ภาษีซื้อต้องห้าม (Non-claimable Input VAT)

ระบบต้องมีรายการให้เลือกและบันทึกเป็นค่าใช้จ่ายแทนภาษีซื้อ:

| กรณี | อ้างอิง |
|------|---------|
| ใบกำกับภาษีมีรายการไม่ครบตาม ม.86/4 | ม.82/5(2) |
| ใบกำกับภาษีอย่างย่อ | ม.86/6 |
| ภาษีซื้อที่ไม่เกี่ยวข้องโดยตรงกับการประกอบกิจการ | ม.82/5(3) |
| ค่ารับรอง | ม.82/5(4) |
| ภาษีซื้อจากรถยนต์นั่ง/โดยสารไม่เกิน 10 คน และค่าใช้จ่ายเกี่ยวกับรถนั้น | ประกาศอธิบดีฯ (ฉบับที่ 42) |
| ใบกำกับภาษีที่ออกโดยผู้ไม่มีสิทธิออก | ม.82/5(5) |
| สำเนาใบกำกับภาษี (ไม่ใช่ต้นฉบับ) | ม.82/5(2) |
| ใบกำกับภาษีที่ได้รับเกิน 6 เดือนนับแต่เดือนที่ออก | ประกาศอธิบดีฯ |

### 1.5 การเฉลี่ยภาษีซื้อ
กิจการที่มีทั้งรายได้ที่ต้องเสีย VAT และได้รับยกเว้น ต้องเฉลี่ยภาษีซื้อของค่าใช้จ่ายส่วนกลาง
```
สัดส่วนที่ขอคืนได้ = รายได้ที่ต้องเสีย VAT ÷ รายได้ทั้งหมด  (ประมาณการจากปีก่อน)
ปรับปรุงจริงตอนสิ้นปี → ปรับปรุงภาษีซื้อในเดือนถัดจากสิ้นรอบบัญชี
```

### 1.6 เหตุผลการออกใบลดหนี้ (`reason_code`) — ม.86/10
```
RETURN_DEFECT      สินค้าชำรุด บกพร่อง ไม่ตรงตามที่ตกลง
RETURN_SHORT       ส่งมอบสินค้าขาดจำนวน
PRICE_REDUCE       ลดราคาสินค้าหรือค่าบริการหลังออกใบกำกับ
SERVICE_INCOMPLETE ให้บริการไม่ครบตามที่ตกลง
CANCEL_CONTRACT    บอกเลิกสัญญาหรือคืนสินค้า
CALC_ERROR         คำนวณราคาสูงกว่าที่เป็นจริง
OTHER              เหตุอื่นตามที่อธิบดีกำหนด (ต้องกรอกคำอธิบาย)
```
เหตุผลการออกใบเพิ่มหนี้ — ม.86/9
```
PRICE_INCREASE     เพิ่มราคาสินค้าหรือค่าบริการหลังออกใบกำกับ
DELIVER_OVER       ส่งมอบสินค้าเกินจำนวน
SERVICE_EXTRA      ให้บริการเกินกว่าที่ตกลง
CALC_ERROR_LOW     คำนวณราคาต่ำกว่าที่เป็นจริง
OTHER              เหตุอื่น (ต้องกรอกคำอธิบาย)
```
**ระบบต้องบังคับ:** ใบลดหนี้ห้ามมีมูลค่าเกินใบกำกับเดิมหักด้วยใบลดหนี้ที่เคยออกไปแล้ว

### 1.7 การยื่น ภ.พ.30
```
ภาษีขายทั้งเดือน  (จาก tax_transaction WHERE kind='vat_output')
− ภาษีซื้อทั้งเดือน (จาก tax_transaction WHERE kind='vat_input' AND vat_treatment<>'non_claimable')
− เครดิตภาษียกมาจากเดือนก่อน
= ภาษีที่ต้องชำระ (ถ้าเป็นบวก) หรือ เครดิตยกไปเดือนถัดไป (ถ้าเป็นลบ)

ตรวจก่อนยื่น (ระบบต้องเตือน):
  [ ] ยอดภาษีขายในรายงาน = ยอดคงเหลือบัญชี output_vat ในงวด
  [ ] ยอดภาษีซื้อในรายงาน = ยอดคงเหลือบัญชี input_vat ในงวด
  [ ] ไม่มีใบกำกับภาษีซื้อที่ยังไม่แนบไฟล์
  [ ] ไม่มีรายการที่ลงบัญชีในงวดแต่ไม่มีใน tax_transaction
```

**เบี้ยปรับและเงินเพิ่มเมื่อยื่นล่าช้า**
```
เงินเพิ่ม  = ภาษีที่ต้องชำระ × 1.5% ต่อเดือน (เศษของเดือนนับเป็น 1 เดือน)
             แต่ไม่เกินจำนวนภาษีที่ต้องชำระ
เบี้ยปรับ  = 2 เท่าของภาษี (ยื่นเกินกำหนด) หรือ 1 เท่า (ยื่นเพิ่มเติมเอง)
             ลดได้ตามระเบียบกรมสรรพากรเมื่อยื่นภายในกำหนดที่กำหนดไว้
ค่าปรับอาญา = ไม่เกิน 2,000 บาท กรณีไม่ยื่นแบบ
```

## 2. ภาษีเงินได้หัก ณ ที่จ่าย

### 2.1 อัลกอริทึมเลือกอัตรา

```
function resolveWhtRate(payment):
    1. ถ้า payment.amount < 1000 บาท และไม่ใช่สัญญาต่อเนื่อง → ไม่ต้องหัก
    2. หา tax_code จาก payment.income_type
    3. lookup tax_rate WHERE tax_code_id = ?
                         AND payment.date BETWEEN effective_from AND COALESCE(effective_to, '9999-12-31')
                         AND condition_json ⊆ { entity_type: partner.entity_type,
                                                channel:     payment.remittance_channel }
       เรียงตามความจำเพาะของ condition_json มากไปน้อย → เอาแถวแรก
    4. ถ้าผู้รับเป็นบุคคลธรรมดาและ income_type ∈ {40(1), 40(2)}
       → ใช้อัลกอริทึมอัตราก้าวหน้า (ข้อ 4) แทน
    5. wht_amount = ROUND(base_amount × rate ÷ 100, 2)
```

**ฐานที่ใช้คำนวณคือมูลค่าก่อน VAT เสมอ**
```
ตัวอย่าง: ค่าบริการ 10,000 + VAT 700 = 10,700
          หัก ณ ที่จ่าย 3% ของ 10,000 = 300
          จ่ายจริง = 10,700 − 300 = 10,400
```

### 2.2 การเลือกแบบยื่น
```
partner.entity_type = 'individual'  → ภ.ง.ด.3
partner.entity_type = 'juristic'    → ภ.ง.ด.53
income_type ∈ {salary}              → ภ.ง.ด.1
income_type ∈ {dividend, interest}  → ภ.ง.ด.2
ผู้รับอยู่ต่างประเทศ                  → ภ.ง.ด.54
```

### 2.3 e-Withholding Tax — กฎที่พลาดบ่อยที่สุด
```
เมื่อ payment.remittance_channel = 'e_wht':
  ✓ ใช้อัตราลด 1% (ตามช่วงเวลาที่มาตรการมีผล)
  ✓ ธนาคารเป็นผู้นำส่งภาษีและออกหลักฐานอิเล็กทรอนิกส์
  ✗ ห้ามนำรายการนี้เข้าแบบ ภ.ง.ด.3/53 ที่บริษัทยื่นเอง  ← ถ้าพลาด = นำส่งซ้ำ
  ✗ ห้ามออกหนังสือรับรอง 50 ทวิ กระดาษให้ผู้รับ (ธนาคารออกให้แล้ว)

ดังนั้น query สร้างแบบ ภ.ง.ด. ต้องมี:
  WHERE remittance_channel = 'manual'
```

### 2.4 ภาษีหัก ณ ที่จ่ายที่ลูกค้าหักเรา
ตอนรับชำระ ลูกค้าจะจ่ายน้อยกว่ายอดใบแจ้งหนี้
```
Dr เงินฝากธนาคาร               10,400
Dr ภาษีเงินได้ถูกหัก ณ ที่จ่าย     300   ← sub_type 'wht_asset' (1165)
   Cr ลูกหนี้การค้า                    10,700
```
ระบบต้องติดตามว่า **ได้รับหนังสือรับรอง 50 ทวิ ครบหรือยัง** (`wht_cert_received`)
เพราะถ้าไม่มีหลักฐาน จะใช้เครดิตภาษีตอนยื่น ภ.ง.ด.50 ไม่ได้

## 3. ภาษีเงินได้นิติบุคคล

### 3.1 การกระทบยอดบัญชี → ภาษี

```
กำไรสุทธิทางบัญชี (จากงบกำไรขาดทุน)
  + รายจ่ายต้องห้าม/ที่หักไม่ได้
      · ค่ารับรองส่วนที่เกินเพดาน
      · เงินบริจาคส่วนที่เกิน 2% ของกำไรสุทธิ
      · ค่าเสื่อมราคาทางบัญชีส่วนที่เกินอัตราสูงสุดทางภาษี
      · ค่าเสื่อมราคารถยนต์นั่งจากต้นทุนส่วนที่เกิน 1 ล้านบาท
      · เบี้ยปรับ เงินเพิ่ม ค่าปรับทางอาญา
      · รายจ่ายส่วนตัว/ให้โดยเสน่หา
      · รายจ่ายที่พิสูจน์ผู้รับไม่ได้
      · ผลขาดทุนจากการตีราคาสินทรัพย์ลดลง (ที่ยังไม่เกิดขึ้นจริง)
      · ประมาณการหนี้สินและค่าเผื่อต่าง ๆ ที่ยังไม่เกิดขึ้นจริง
  − รายได้ที่ได้รับยกเว้น
      · เงินปันผลที่ได้รับยกเว้นตามเงื่อนไข
      · กำไรจากการตีราคาที่ยังไม่เกิดขึ้นจริง
  − ค่าเสื่อมราคาทางภาษีส่วนที่เกินทางบัญชี (เช่น สิทธิ SME)
  − รายจ่ายที่หักได้เพิ่ม (เช่น ค่าลงทุนระบบ e-Tax หักได้ 2 เท่า)
= กำไรสุทธิทางภาษีก่อนหักผลขาดทุน
  − ผลขาดทุนสุทธิยกมาไม่เกิน 5 รอบระยะเวลาบัญชี
= กำไรสุทธิทางภาษี → คูณอัตราตามขั้น
  − ภาษีที่ถูกหัก ณ ที่จ่าย
  − ภาษีที่ชำระตาม ภ.ง.ด.51
= ภาษีที่ต้องชำระเพิ่ม / ขอคืน
```

### 3.2 ภ.ง.ด.51 — การเตือนความเสี่ยง 25%

```
ภาษีครึ่งปี = (ประมาณการกำไรสุทธิทั้งปี × อัตราภาษี) ÷ 2

ตรวจสอบตอนสิ้นปี:
  shortfall_pct = (กำไรสุทธิจริง − ประมาณการ) × 100 ÷ กำไรสุทธิจริง
  ถ้า shortfall_pct > 25% และไม่มีเหตุอันสมควร
     → เงินเพิ่ม 20% ของภาษีที่ชำระขาด

ระบบต้องทำ:
  1. ตอนกรอกประมาณการ: แสดง "ถ้ากำไรจริงเกิน X บาท คุณจะเข้าข่ายเงินเพิ่ม 20%"
     โดย X = ประมาณการ ÷ 0.75
  2. ทุกเดือนหลังยื่น ภ.ง.ด.51: เทียบผลจริงสะสมกับประมาณการ
     แจ้งเตือนเมื่อแนวโน้มทั้งปีจะเกิน X
  3. ตอนปิดปี: คำนวณเงินเพิ่มให้อัตโนมัติถ้าเข้าเงื่อนไข
```

### 3.3 เกณฑ์ SME
```
เป็น SME เมื่อ (ทั้งสองข้อพร้อมกัน):
  · ทุนจดทะเบียนที่ชำระแล้ว ณ วันสิ้นรอบบัญชี ≤ 5,000,000 บาท
  · รายได้จากการขายสินค้าและบริการในรอบบัญชี ≤ 30,000,000 บาท
→ ใช้ขั้นภาษี taxpayer_kind = 'juristic_sme'
ระบบต้องคำนวณสถานะนี้อัตโนมัติทุกสิ้นรอบบัญชี ไม่ให้ผู้ใช้ติ๊กเอง
```

## 4. ภาษีเงินได้บุคคลธรรมดา (สำหรับเงินเดือน)

### 4.1 วิธีคำนวณแบบเฉลี่ยทั้งปี (annualized) — ที่ใช้จริงในการหักเงินเดือน

```
ขั้นที่ 1  เงินได้ทั้งปีโดยประมาณ
           = (เงินเดือน × จำนวนงวดที่เหลือทั้งปี) + เงินได้ที่จ่ายไปแล้วในปีนี้
             + โบนัส/เงินได้อื่นที่รู้แน่นอน

ขั้นที่ 2  หักค่าใช้จ่าย
           = MIN(เงินได้ × 50%, 100,000)

ขั้นที่ 3  หักค่าลดหย่อน (จาก employee_tax_allowance + pit_deduction_rule)
           ส่วนตัว 60,000 + คู่สมรส + บุตร + บิดามารดา + ประกัน + กองทุน + ...
           ★ เงินสมทบประกันสังคมใช้ยอดที่จะจ่ายจริงทั้งปี ตามเพดานที่มีผลในปีนั้น

ขั้นที่ 4  เงินได้สุทธิ = ขั้น 1 − ขั้น 2 − ขั้น 3

ขั้นที่ 5  คำนวณภาษีทั้งปีตามขั้นบันได (income_tax_bracket)
           ★ เป็นอัตราก้าวหน้าแบบขั้นบันได ไม่ใช่คูณอัตราเดียวทั้งก้อน

ขั้นที่ 6  ภาษีที่หักงวดนี้
           = (ภาษีทั้งปี − ภาษีที่หักไปแล้วในปีนี้) ÷ จำนวนงวดที่เหลือ

ขั้นที่ 7  ปัดเศษเป็นทศนิยม 2 ตำแหน่ง
```

**ตัวอย่างที่ควรเป็น test case**
```
เงินเดือน 50,000 บาท/เดือน, โสด, ไม่มีลดหย่อนอื่น, ประกันสังคมเพดาน 2569
  เงินได้ทั้งปี        = 600,000
  หักค่าใช้จ่าย        = 100,000  (50% = 300,000 แต่เพดาน 100,000)
  หักส่วนตัว           =  60,000
  หักประกันสังคม       =  10,500  (875 × 12)
  เงินได้สุทธิ         = 429,500
  ภาษี = (300,000−150,000)×5% + (429,500−300,000)×10%
       = 7,500 + 12,950 = 20,450 บาท/ปี
  หักเดือนละ = 20,450 ÷ 12 = 1,704.17 บาท
```

### 4.2 ประกันสังคม
```
sso_wage_base  = LEAST(GREATEST(ค่าจ้างในเดือน, wage_floor), wage_ceiling)
                 ← lookup sso_rate ด้วยวันที่จ่ายเงินเดือน
employee_sso   = ROUND(sso_wage_base × employee_percent ÷ 100, 0)   ← ปัดเป็นจำนวนเต็ม
employer_sso   = ROUND(sso_wage_base × employer_percent ÷ 100, 0)

ปี 2568: ceiling 15,000 → สูงสุด 750 บาท
ปี 2569: ceiling 17,500 → สูงสุด 875 บาท
```
**ห้ามใช้ค่าคงที่ 750 หรือ 15,000 ในโค้ด** — เพดานจะปรับอีกในปี 2572 และ 2575

### 4.3 ค่าล่วงเวลา (พ.ร.บ.คุ้มครองแรงงาน)
```
ค่าจ้างรายชั่วโมง = ค่าจ้างรายเดือน ÷ 30 ÷ ชั่วโมงทำงานปกติต่อวัน

OT วันทำงานปกติ         = ชั่วโมง × อัตรารายชั่วโมง × 1.5
ทำงานในวันหยุด           = ชั่วโมง × อัตรารายชั่วโมง × 1.0 (ลูกจ้างรายเดือน) หรือ × 2.0 (รายวัน)
OT ในวันหยุด            = ชั่วโมง × อัตรารายชั่วโมง × 3.0
```

## 5. ค่าเสื่อมราคา

### 5.1 วิธีเส้นตรง
```
ค่าเสื่อมต่อปี = (ราคาทุน − มูลค่าคงเหลือ) ÷ อายุการใช้งาน
ค่าเสื่อมต่อเดือน = ค่าเสื่อมต่อปี ÷ 12

ปีแรก คิดตามจำนวนวันที่ใช้งานจริง:
  ค่าเสื่อมปีแรก = ค่าเสื่อมต่อปี × (จำนวนวันนับจากวันที่พร้อมใช้งานถึงสิ้นรอบบัญชี) ÷ 365
```

### 5.2 ทางบัญชี vs ทางภาษี — ต้องคำนวณแยกกันเสมอ
```
ทางบัญชี: ใช้อายุการใช้งานที่ประมาณตามความเป็นจริง (TFRS for NPAEs บทที่ 10)
ทางภาษี:  ห้ามเกินอัตราสูงสุดตาม พ.ร.ฎ.145 (tax_depreciation_rate)

ผลต่างของสองตัวนี้ → เข้ากระดาษทำการกระทบยอด ภ.ง.ด.50
  ค่าเสื่อมบัญชี > ค่าเสื่อมภาษี → บวกกลับส่วนต่าง
  ค่าเสื่อมภาษี > ค่าเสื่อมบัญชี → หักออกส่วนต่าง
```

### 5.3 กรณีพิเศษที่ระบบต้องรองรับ

| กรณี | กฎ |
|------|-----|
| รถยนต์นั่งไม่เกิน 10 คน | หักค่าเสื่อมจากต้นทุนไม่เกิน 1,000,000 บาท ส่วนเกินเป็นรายจ่ายต้องห้าม |
| SME — คอมพิวเตอร์ | หักเบื้องต้น 40% ในวันที่ได้มา ที่เหลือหักภายใน 3 รอบบัญชี |
| SME — เครื่องจักร | หักเบื้องต้น 40% ในวันที่ได้มา ที่เหลือหักภายใน 5 รอบบัญชี |
| SME — อาคารโรงงาน | หักเบื้องต้น 25% ส่วนที่เหลือหักในอัตราไม่เกิน 5% ต่อปี |

| ทรัพย์สินที่หักครบแล้ว | เหลือมูลค่าทางบัญชี 1 บาทต่อรายการ (แนวปฏิบัติ) จนกว่าจะจำหน่าย |

```
เมื่อปิดบัญชีประจำปีและมีกำไรสุทธิ:
  ถ้า ทุนสำรองสะสม < 10% ของทุนจดทะเบียน:
     จัดสรร = MIN(กำไรสุทธิ × 5%, 10% ของทุนจดทะเบียน − ทุนสำรองสะสม)
     Dr กำไรสะสม  Cr สำรองตามกฎหมาย
```

## 7. อากรแสตมป์ (บัญชีอัตราอากรแสตมป์)

| ตราสาร | อัตรา |
|--------|-------|
| เช่าที่ดิน โรงเรือน สิ่งปลูกสร้าง | 1 บาท ต่อทุก 1,000 บาทของค่าเช่าตลอดอายุสัญญา |
| จ้างทำของ | 1 บาท ต่อทุก 1,000 บาทของสินจ้าง |
