# 22 — ทำงานแบบเดียวกับโปรแกรมที่นักบัญชีคุ้นมือ (FlowAccount)

เป้าหมาย: คนที่ใช้ FlowAccount อยู่ ย้ายมาแล้วกรอกเอกสาร ทำข้อมูล และใช้ข้อมูลได้ด้วยมือเดิม
เราเลียนแบบ **ลำดับการกรอก โครงข้อมูล สถานะ และการไหลของเอกสาร** เท่านั้น
ไม่ใช้ชื่อ โลโก้ สี ข้อความ หรือโค้ดของเขา — หน้าตายังเป็นระบบดีไซน์ของเราเอง (`webapp/design.md`)

## ที่มาของข้อมูล

| แหล่ง | ใช้ทำอะไร |
|---|---|
| Open API ของ FlowAccount (`github.com/flowaccount/open-api`, สัญญาอนุญาต MIT) — สเปกที่ใช้งานจริง `libs/api-mcp/spec/openapi.yaml` และฉบับร่าง `libs/api-spec` | โครงข้อมูลเอกสาร ช่องทุกช่อง ค่าคงที่ สถานะ การรับ/จ่ายชำระ เลขที่เอกสาร |
| ผลค้นหาหน้าคู่มือของ FlowAccount (เปิดหน้าเต็มไม่ได้ — ถูกปิดกั้นจากเครือข่าย) | ลำดับช่องในฟอร์ม ชื่อสถานะที่แสดง ปุ่มและเมนู |

รายงานวิจัยฉบับเต็มเก็บไว้นอกรีโป (โฟลเดอร์ชั่วคราวของงาน) ข้อสรุปทั้งหมดอยู่ในเอกสารนี้

## ข้อสรุปจากการศึกษา

1. **เอกสารขายและซื้อทุกชนิดใช้หัวเอกสารชุดเดียวกัน** — ข้อมูลคู่ค้า (คัดลอกลงเอกสาร แก้บนใบได้) วันที่
   เงื่อนไขชำระ 3 แบบ (เงินสด · เครดิต N วัน · เครดิตไม่แสดงวันครบกำหนด) วันครบกำหนด โปรเจกต์ พนักงานขาย
   เลขที่อ้างอิง ราคารวม/ไม่รวมภาษี หมายเหตุ (พิมพ์) โน้ตภายใน (ไม่พิมพ์)
2. **ราคา** — ส่วนลดต่อบรรทัด (% หรือบาท ทั้งใบใช้หน่วยเดียว) ส่วนลดท้ายบิล (% หรือบาท) หักก่อนภาษีเสมอ
   ภาษีต่อบรรทัด 7% / 0% / ยกเว้น · ราคารวมภาษีถอดภาษี ×7/107 · ยอดท้ายเอกสาร: รวมเป็นเงิน → ส่วนลด →
   ราคาหลังหักส่วนลด → ยอดยกเว้น → มูลค่าที่คิดภาษี → ภาษี → รวมทั้งสิ้น → หัก ณ ที่จ่าย
3. **การไหลของเอกสาร** — ใบเสนอราคา → ใบวางบิล/ใบแจ้งหนี้ → ใบกำกับภาษี → ใบเสร็จรับเงิน (ข้ามขั้นได้)
   · ใบเสนอราคา → ขายเงินสด · ใบสั่งซื้อ → ใบรับสินค้า/ตั้งหนี้ หรือ → ค่าใช้จ่าย · เอกสารปลายทางได้ข้อมูลครบ ไม่ต้องกรอกซ้ำ
   และเก็บลิงก์ทั้งสองทาง
4. **สถานะตามชนิดเอกสาร** และ **ป้ายสถานะคือเมนู** — กดป้ายในรายการ เห็นสิ่งที่ทำต่อได้ตามลำดับการไหล
5. **แก้ไขได้เฉพาะสถานะแรก** — ใบที่ไปต่อแล้วต้องรีเซ็ต (และลบ/ยกเลิกเอกสารปลายทางก่อน)
6. **หน้าต่างรับชำระ** — วิธีชำระ บัญชีที่รับ ธนาคารผู้จ่าย เช็ค ยอดรับสุทธิ ค่าธรรมเนียม หัก ณ ที่จ่าย (% หรือจำนวน)
   รายการปรับลด (ส่วนลดพิเศษ ค่านายหน้า ค่าดำเนินการ ปัดเศษ) ส่วนต่าง (เงินขาด/เกิน ค่าธรรมเนียมธนาคาร) รับบางส่วนได้
7. **เลขที่เอกสาร** — คำนำหน้า + ปี ค.ศ. + เดือน + เลขรัน 4 หลัก (`INV2026060001`) หรือนับใหม่ทุกปี
   คำนำหน้าตั้งเองได้ (ไม่เกิน 6 ตัว)
8. **สมุดรายชื่อ** — ลูกค้า / ผู้จำหน่าย / ผู้จำหน่ายและลูกค้า · บุคคลธรรมดา / นิติบุคคล · สาขา · ผู้ติดต่อ อีเมล มือถือ
   โทรศัพท์ แฟกซ์ เว็บไซต์ รหัสไปรษณีย์ ที่อยู่จัดส่ง เครดิต (วัน) บัญชีธนาคาร
9. **สินค้า** — บริการ / สินค้าไม่นับสต๊อก / สินค้านับสต๊อก · ราคาขายและราคาซื้อ แต่ละฝั่งมีชนิดภาษี 4 แบบ
   (รวม / ไม่รวม / 0% / ยกเว้น) · บาร์โค้ด · บัญชีรายได้/ค่าใช้จ่าย

## เทียบกับระบบเรา

| เรื่อง | FlowAccount | ระบบเราก่อนรอบนี้ | รอบนี้ |
|---|---|---|---|
| ส่วนลดรายการ / ท้ายบิล | มี | ไม่มี | **ทำแล้ว** ทุกเอกสาร ลงบัญชีด้วยยอดหลังหักส่วนลด |
| ราคารวม/ไม่รวมภาษี | ทุกเอกสาร | เฉพาะขายเงินสด | **ทำแล้ว** ทุกเอกสาร |
| เงื่อนไขชำระ 3 แบบ + วันครบกำหนดแก้ได้ | มี | ใช้เครดิตตามทะเบียนอย่างเดียว | **ทำแล้ว** |
| โปรเจกต์ พนักงานขาย เลขอ้างอิง หมายเหตุ โน้ตภายใน | มี | หมายเหตุบางเอกสาร | **ทำแล้ว** ส่งต่อตอนแปลงเอกสาร |
| แก้ข้อมูลลูกค้าบนเอกสาร (สาขาอื่น) | มี | ไม่ได้ | **ทำแล้ว** ทะเบียนไม่เปลี่ยน รายงานภาษีใช้สาขาตามใบ |
| ยอดท้ายเอกสารแบบเต็ม | มี | ยอดรวมบรรทัดเดียว | **ทำแล้ว** |
| เลขที่เอกสาร | `INV2026060001` ตั้งคำนำหน้าได้ | `INV2606-00001` ตายตัว | **ทำแล้ว** บริษัทเดิมคงรูปแบบเดิมจนกว่าจะเปลี่ยน |
| ผู้จำหน่ายและลูกค้าในรายเดียว | มี | ต้องสร้างสองราย | **ทำแล้ว** |
| ช่องสมุดรายชื่อ (ผู้ติดต่อ อีเมล ธนาคาร ฯลฯ) | มี | ชื่อ ที่อยู่ โทร | **ทำแล้ว** ข้อมูล ฟอร์ม 5 กลุ่ม ทะเบียน |
| สินค้าไม่นับสต๊อก · ราคาซื้อ · ชนิดภาษี · บาร์โค้ด | มี | บริการ/สินค้า ราคาเดียว | **ทำแล้ว** ข้อมูล ฟอร์มฝั่งขาย/ซื้อ ทะเบียน |
| ชื่อสถานะตามชนิดเอกสาร · ป้ายสถานะเป็นเมนู | มี | ป้ายทั่วไป | **ทำแล้ว** เอกสารขายทุกชนิด (อนุมัติ/ไม่อนุมัติ/รีเซ็ต สร้างเอกสารถัดไป รับชำระ) |
| ใบวางบิล/ใบแจ้งหนี้ก่อนออกใบกำกับ | มี | ใบวางบิลรวมใบกำกับที่ออกแล้วเท่านั้น | **ทำแล้ว** รอวางบิล → วางบิลแล้ว → เปิดบิลแล้ว ไม่ลงบัญชี ใบวางบิลรวมแบบเดิมยังใช้ได้ |
| แก้ใบกำกับที่ยังไม่ส่งลูกค้า (รอดำเนินการ) | มี | ต้องยกเลิกแล้วออกใหม่ | **ทำแล้ว** เลขเดิม กลับรายการเดิมแล้วลงใหม่ในชุดเดียว เก็บประวัติการแก้ |
| ออกใบกำกับพร้อมรับเงิน | มี | ทำสองขั้น | **ทำแล้ว** ใบกำกับ + ใบเสร็จในขั้นเดียว |
| หน้าต่างรับ/จ่ายชำระครบทุกช่อง | มี | ส่วนใหญ่มีแล้ว | **ทำแล้ว** รับชำระ: วิธีชำระ เช็ค ธนาคารผู้จ่าย ค่าธรรมเนียม ปรับลด ส่วนต่าง · จ่ายชำระ: 6 วิธี เช็ค ค่าธรรมเนียม หัก ณ ที่จ่ายพิมพ์ยอดเองได้ |
| ใบสั่งซื้อ → ค่าใช้จ่าย | มี | ไม่มี | **ทำแล้ว** จ่ายทันทีหรือจ่ายทีหลังได้ |
| ค่าใช้จ่ายจ่ายทีหลัง | มี | จ่ายทันทีเท่านั้น | **ทำแล้ว** ตั้งเป็นเจ้าหนี้รอจ่าย หัก ณ ที่จ่ายและออก 50 ทวิ ตอนจ่าย |
| ฟอร์มตั้งหนี้/ค่าใช้จ่ายแบบหัวเอกสารกลาง | มี | ฟอร์มแยกแบบเก่า | **ทำแล้ว** วันที่ใบกำกับผู้ขาย ภ.ง.ด.3/53 ตามผู้รับเงิน |
| ฟอร์มสมุดรายชื่อ/สินค้า/ตั้งค่าเลขที่ | มี | — | **ทำแล้ว** ตั้งคำนำหน้า รอบนับ เห็นเลขถัดไปทันที |
| ค่าเริ่มต้นราคารวม/ไม่รวมภาษีของเอกสารใหม่ | มี | ไม่มี | **ทำแล้ว** ตั้งค่า > ฟังก์ชันเอกสาร |
| นำเข้าผู้ติดต่อ/สินค้าจาก Excel | ดูตัวอย่าง ข้ามซ้ำ ประวัติ ไฟล์แถวที่ไม่ผ่าน | ไม่มี | **ทำแล้ว** อ่านไฟล์จากโปรแกรมเดิมได้ด้วย |

## สิ่งที่ตั้งใจทำต่างจากต้นแบบ

| เรื่อง | เหตุผล |
|---|---|
| เลขที่เอกสารจองตอนลงบัญชี ไม่ใช่ตอนสร้างร่าง | ใบกำกับภาษีต้องเรียงเลขไม่ขาดช่วง ต้นแบบลบเอกสารแล้วเลขหาย |
| ทุกเอกสารลงบัญชีทันทีและแก้ด้วยการกลับรายการ | สมุดบัญชีต้องย้อนตรวจได้ทุกรายการ |
| สมุดรายวันใช้คำนำหน้าเดิม | ไม่กระทบเลขใบสำคัญที่อ้างอิงอยู่ในรายงานเดิม |
| บริษัทที่มีข้อมูลอยู่แล้วคงรูปแบบเลขเดิม | เลขเล่มเดียวกันไม่ควรเปลี่ยนรูปกลางงวด เปลี่ยนได้เองที่หน้าตั้งค่า (เลขรันต่อเนื่อง) |
| รหัสผู้ติดต่อตั้งเองได้เฉพาะตอนสร้าง | เอกสารและใบสำคัญอ้างรหัสนี้ เปลี่ยนภายหลังแล้วรายงานเดิมหาคู่ค้าไม่เจอ |
| รายที่มีเอกสารแล้วเพิ่มบทบาทได้ แต่ตัดบทบาทเดิมไม่ได้ | เอกสารเดิมต้องยังอยู่ในทะเบียนฝั่งเดิม (ลูกหนี้/เจ้าหนี้) |
| นำเข้าผู้ติดต่อที่มีอยู่แล้วแต่คนละบทบาท ตั้งเป็นผู้จำหน่ายและลูกค้าให้ | หนึ่งเลขผู้เสียภาษี + สาขา = หนึ่งรายชื่อ ไม่แตกเป็นสองรายจนกระทบยอดไม่ได้ |
