# ที่มาของไฟล์ PDF ในโฟลเดอร์นี้

`คู่มือย้ายข้อมูลจาก-FlowAccount.pdf` สร้างจากไฟล์ในโฟลเดอร์นี้ ไม่ได้พิมพ์มือ

| ไฟล์ | หน้าที่ |
|---|---|
| `guide-body.html` | เนื้อหา 9 หน้า (แต่ละ `<div class="page">` = 1 หน้ากระดาษ) |
| `guide-style.css` | สไตล์สำหรับพิมพ์ A4 |

## วิธีสร้างใหม่

1. โหลดฟอนต์ Sarabun (Regular / SemiBold / Bold) จาก Google Fonts
   แล้วฝังเป็น base64 ใน `@font-face` — ต้องฝัง ไม่งั้นภาษาไทยจะกลายเป็นกล่องเปล่าตอนแปลงเป็น PDF
2. ต่อไฟล์เป็น HTML เดียว: `<style>` = ฟอนต์ + `guide-style.css`, `<body>` = `guide-body.html`
3. แปลงเป็น PDF ด้วย Chromium (Playwright `page.pdf`) — A4, `printBackground: true`, margin 0
   (ระยะขอบอยู่ใน CSS แล้ว ถ้าตั้ง margin ซ้ำหน้าจะล้นเกินจำนวนที่ควรเป็น)
4. ตรวจว่าได้ **9 หน้า** พอดี และเปิดดูว่าตัวอักษรไทยขึ้นครบ ไม่ใช่กล่องสี่เหลี่ยม

## เวลาแก้เนื้อหา

แต่ละหน้าถูกบังคับให้ขึ้นหน้าใหม่ ถ้าเพิ่มเนื้อหาจนเกิน 1 หน้ากระดาษ จะดันไปเป็นหน้าเกิน
แก้ได้โดยลดระยะห่างใน `guide-style.css` หรือย้ายเนื้อหาไปหน้าถัดไป
