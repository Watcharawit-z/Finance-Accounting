# 02 — ขอบเขตโมดูลทั้งหมด (14 หมวด)

สัญลักษณ์เฟส: **P1** = MVP ใช้ในบริษัทตัวเอง · **P2** = พร้อมขาย · **P3** = Enterprise · **P4** = AI/ขั้นสูง

## หมวด 1 — บัญชีแกนกลาง (General Ledger)

| ฟีเจอร์ | เฟส | รายละเอียด |
|---------|-----|------------|
| ผังบัญชี (Chart of Accounts) | P1 | 5 หมวดมาตรฐานไทย, รหัสแบบลำดับชั้น 4–6 ระดับ, ชื่อไทย+อังกฤษ, ผูก tax code เริ่มต้น |
| สมุดรายวัน (Journal Entry) | P1 | ทั่วไป/ซื้อ/ขาย/รับเงิน/จ่ายเงิน, เดบิต=เครดิตเสมอ, ผ่านสถานะ draft→posted |
| การกลับรายการ (Reversal) | P1 | ห้ามลบ JE ที่ post แล้ว — กลับรายการพร้อมอ้างอิงต้นทาง |
| รายการซ้ำ (Recurring JE) | P1 | ค่าเช่า ค่าเสื่อม ค่าตัดจำหน่าย — สร้างอัตโนมัติตามตาราง |
| งวดบัญชีและการล็อก | P1 | ล็อกรายงวด/รายโมดูล, ปลดล็อกได้เฉพาะ role ที่กำหนด + บันทึกเหตุผล |
| ปิดบัญชีสิ้นงวด/สิ้นปี | P1 | Checklist ปิดงบ, ปิดบัญชีรายได้-ค่าใช้จ่ายเข้ากำไรสะสม, ยกยอดต้นงวด |
| หลายสกุลเงิน | P2 | อัตราแลกเปลี่ยนรายวัน (ดึงจาก BOT), กำไร/ขาดทุนอัตราแลกเปลี่ยนที่เกิดขึ้นจริงและยังไม่เกิดขึ้น, revaluation สิ้นงวด |
| มิติทางบัญชี (Dimensions) | P2 | Cost center, Department, Project, Branch, Product line — ทุก JE line เก็บมิติได้ |
| หลายบริษัท / สาขา | P2 | Company hierarchy, รายการระหว่างกัน (intercompany), รายงานแยกและรวม |
| งบการเงินรวม (Consolidation) | P3 | ตัดรายการระหว่างกัน, ส่วนได้เสียที่ไม่มีอำนาจควบคุม, แปลงค่างบต่างประเทศ |
| การจัดสรรต้นทุน (Allocation) | P3 | กระจายค่าใช้จ่ายส่วนกลางตามสัดส่วนที่ตั้งไว้ |

## หมวด 2 — ลูกหนี้และการขาย (Accounts Receivable)

| ฟีเจอร์ | เฟส | รายละเอียด |
|---------|-----|------------|
| ทะเบียนลูกค้า | P1 | เลขผู้เสียภาษี 13 หลัก, สาขา, ที่อยู่ออกใบกำกับ vs ที่อยู่จัดส่ง, เงื่อนไขชำระ, วงเงินเครดิต |
| ใบเสนอราคา (Quotation) | P1 | เทมเพลตพิมพ์, อนุมัติ, แปลงเป็นใบสั่งขาย, หมดอายุอัตโนมัติ |
| ใบสั่งขาย (Sales Order) | P2 | จองสต๊อก, ทยอยส่งของ (partial delivery) |
| ใบส่งของ / ใบแจ้งหนี้ | P1 | รวมหลายใบส่งของเป็น 1 ใบแจ้งหนี้ (consolidated billing) |
| **ใบกำกับภาษี** | P1 | ครบตาม ม.86/4, เลขที่เรียงลำดับตามสาขา, พิมพ์ต้นฉบับ/สำเนา, สถานะ e-Tax |
| ใบเสร็จรับเงิน / ใบรับชำระ | P1 | เงินสด/โอน/เช็ค/บัตร, หักภาษี ณ ที่จ่ายที่ลูกค้าหักไว้, ค่าธรรมเนียมธนาคาร |
| ใบเพิ่มหนี้ / ใบลดหนี้ | P1 | ต้องอ้างใบกำกับเดิม + เหตุผลตามกฎหมาย |
| เงินมัดจำ / เงินรับล่วงหน้า | P1 | บัญชีหนี้สิน, ตัดกับใบแจ้งหนี้ภายหลัง, ประเด็น VAT ณ วันรับเงิน |
| ตั้งหนี้อัตโนมัติซ้ำ (Recurring invoice) | P2 | ค่าบริการรายเดือน/รายปี |
| อายุหนี้และการติดตาม | P1 | Aging 30/60/90/120+, ใบวางบิล/ใบแจ้งหนี้ค้างชำระ, ตารางวางบิล-รับเช็ค |
| จดหมายทวงถามอัตโนมัติ (Dunning) | P2 | ระดับ 1–4 ตามอายุหนี้, ส่งอีเมล/LINE |
| ค่าเผื่อหนี้สงสัยจะสูญ | P2 | ตั้งตามอายุหนี้ (aging matrix), ตัดหนี้สูญตามหลักเกณฑ์กรมสรรพากร |
| Customer Portal | P3 | ลูกค้าดูใบแจ้งหนี้/ดาวน์โหลดใบกำกับภาษี/แจ้งชำระเงิน |
| การรับรู้รายได้ตามงวด | P3 | สำหรับสัญญาบริการ/โครงการ (เตรียมรองรับ TFRS 15) |

## หมวด 3 — เจ้าหนี้และการจัดซื้อ (Accounts Payable & Procurement)

| ฟีเจอร์ | เฟส | รายละเอียด |
|---------|-----|------------|
| ทะเบียนผู้ขาย | P1 | เลขผู้เสียภาษี, ประเภท (บุคคล/นิติบุคคล) → ผูกกับ ภ.ง.ด.3 หรือ 53 อัตโนมัติ |
| ใบขอซื้อ (PR) | P2 | เส้นทางอนุมัติตามวงเงิน |
| ใบสั่งซื้อ (PO) | P2 | เปรียบเทียบราคา, ติดตามของที่ยังไม่ได้รับ |
| ใบรับสินค้า (GR) | P2 | รับบางส่วน, ผูกเข้าสต๊อก |
| ตั้งหนี้ (Vendor Bill) | P1 | จับคู่ 3 ทาง PO–GR–Bill, บันทึกภาษีซื้อ, ตรวจใบกำกับภาษีซื้อครบถ้วน |
| ใบสำคัญจ่าย / การจ่ายชำระ | P1 | จ่ายหลายบิลในครั้งเดียว, หัก WHT อัตโนมัติ, ออก 50 ทวิ พร้อมกัน |
| ทะเบียนเช็คจ่าย | P1 | เลขที่เช็ค, วันที่ลงเช็ค (post-dated), สถานะขึ้นเงิน/ยกเลิก |
| ไฟล์โอนเงินธนาคาร | P2 | สร้างไฟล์ตามฟอร์แมตธนาคาร (SCB/KBank/BBL/KTB) หรือผ่าน API |
| เบิกค่าใช้จ่ายพนักงาน | P2 | แนบใบเสร็จ, อนุมัติหลายชั้น, จ่ายคืนพร้อมเงินเดือน |
| เงินสดย่อย (Petty Cash) | P1 | วงเงินคงที่ (imprest), เบิกชดเชย |
| เงินทดรองจ่าย (Advance) | P2 | จ่ายล่วงหน้า → เคลียร์ตามจริง → คืนเงิน/เบิกเพิ่ม |
| อายุเจ้าหนี้ | P1 | Aging, ประมาณการเงินที่ต้องจ่ายรายสัปดาห์ |

| ควบคุมงบประมาณ | P3 | บล็อก/เตือน ตอนสร้าง PR/PO ที่เกินงบ |

## หมวด 11 — รายงานการเงิน (Financial Reporting)

**รายงานตามกฎหมาย (P1)**
- งบทดลอง (Trial Balance) — ก่อน/หลังปรับปรุง
- งบแสดงฐานะการเงิน (Statement of Financial Position)
- งบกำไรขาดทุน (แบบจำแนกค่าใช้จ่ายตามหน้าที่ และตามลักษณะ)
- งบกระแสเงินสด (ทางอ้อม P1 / ทางตรง P2)
- งบแสดงการเปลี่ยนแปลงส่วนของผู้ถือหุ้น
- หมายเหตุประกอบงบการเงิน (template ตาม TFRS for NPAEs)
- บัญชีแยกประเภททั่วไป / รายละเอียดรายบัญชี
- สมุดรายวันทั้ง 5 เล่ม

**รายงานบริหาร (P2)**
- เปรียบเทียบงวด/ปี, ย่อส่วนร้อยละ (common-size)
- P&L รายมิติ (แผนก/โครงการ/สาขา/สินค้า)
- อัตราส่วนทางการเงิน: สภาพคล่อง, ความสามารถทำกำไร, ประสิทธิภาพ (DSO, DIO, DPO, CCC), หนี้สินต่อทุน
- กราฟแนวโน้ม 13 เดือน, กระแสเงินสด 13 สัปดาห์

**เครื่องมือ (P2–P3)**
- Report Builder — ผู้ใช้กำหนดโครงสร้างรายงานเองจากกลุ่มบัญชี
- Drill-down ทุกตัวเลข → GL → JE → เอกสาร → ไฟล์แนบ
- ตารางเวลา (schedule) ส่งรายงานอัตโนมัติทางอีเมล
- Export: Excel (มีสูตรจริง), PDF, CSV, API

## เมทริกซ์ความสัมพันธ์ระหว่างเอกสารกับบัญชี (สรุป)

| เอกสาร | เดบิต | เครดิต |
|--------|-------|--------|
| ใบกำกับภาษี/ขายเชื่อ | ลูกหนี้การค้า | รายได้ + ภาษีขาย |
| รับชำระจากลูกค้า | เงินฝากธนาคาร + ภาษีถูกหัก ณ ที่จ่าย | ลูกหนี้การค้า |
| ตั้งหนี้ผู้ขาย | ค่าใช้จ่าย/สินค้า + ภาษีซื้อ | เจ้าหนี้การค้า |
| จ่ายชำระผู้ขาย | เจ้าหนี้การค้า | เงินฝากธนาคาร + ภาษีหัก ณ ที่จ่ายค้างนำส่ง |
| รับสินค้าเข้าคลัง (perpetual) | สินค้าคงเหลือ | พักรับสินค้า/เจ้าหนี้ |
| ขายสินค้า (ตัดต้นทุน) | ต้นทุนขาย | สินค้าคงเหลือ |
| ค่าเสื่อมราคาประจำเดือน | ค่าเสื่อมราคา | ค่าเสื่อมราคาสะสม |
| เงินเดือน | เงินเดือน + สมทบประกันสังคมนายจ้าง | เงินสด/ธนาคาร + ภาษีหัก ณ ที่จ่ายค้าง + ประกันสังคมค้างนำส่ง |
| ปิดภาษี VAT รายเดือน | ภาษีขาย | ภาษีซื้อ + ภาษีมูลค่าเพิ่มค้างชำระ |
