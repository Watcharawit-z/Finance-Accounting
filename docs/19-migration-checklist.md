# 19 — ใบตรวจสำหรับวันย้ายข้อมูลจริง

พิมพ์หน้านี้ไว้ข้างตัวตอนย้ายข้อมูล ทำตามลำดับ อย่าข้ามข้อ

## ก่อนเริ่ม

- [ ] เลือก **วันตัดยอด** — ควรเป็นวันสิ้นเดือนที่ปิดงบในระบบเดิมแล้ว
- [ ] ในระบบเดิม **หยุดออกเอกสารใหม่** ตั้งแต่วันตัดยอด จนกว่าจะย้ายเสร็จ
      ถ้ายังออกต่อ ตัวเลขจะวิ่งหนีตลอดและไม่มีทางกระทบยอดได้
- [ ] ดาวน์โหลดจาก FlowAccount ไว้ให้ครบ 3 ไฟล์
  - [ ] **งบทดลอง ณ วันตัดยอด** (รายงานด้านบัญชี → งบทดลอง)
  - [ ] **รายงานอายุลูกหนี้ ณ วันตัดยอด** — ใช้ตรวจ ไม่ได้นำเข้า
  - [ ] **รายงานอายุเจ้าหนี้ ณ วันตัดยอด** — ใช้ตรวจ ไม่ได้นำเข้า

## ขั้นที่ 1 — ดึงข้อมูล

```bash
node tools/flowaccount-import/pull.js --config config.json --from 2026-01-01 --to 2026-07-31
```

- [ ] ดูสรุปท้ายคำสั่ง ทุกชุดต้องขึ้นจำนวน ไม่มีคำว่า "ผิดพลาด"
- [ ] ถ้าชุดไหนขึ้น 0 ทั้งที่ควรมีข้อมูล ให้หยุดแล้วตรวจสิทธิ์ของ client id ก่อน

## ขั้นที่ 2 — แปลงและตรวจ

```bash
node tools/flowaccount-import/convert.js --cutoff 2026-07-31 --tb งบทดลอง.csv
```

ดูผลสามส่วนนี้ ทุกข้อต้องผ่านก่อนไปต่อ

- [ ] **`errors.csv` ต้องว่างเปล่า** — ถ้ามีบรรทัด แปลว่ามีเอกสารที่แปลงไม่ได้
      ต้องไปแก้ที่ระบบเดิมแล้วดึงใหม่ ห้ามนำเข้าทั้งที่ยังมีบรรทัดค้าง
- [ ] **ตารางความครบถ้วน** — คอลัมน์ "แปลงไม่ได้" ต้องเป็น 0 ทุกแถว
      ส่วนคอลัมน์ "ซ้ำ" ไม่เป็นไร แปลว่าระบบตัดเอกสารเลขซ้ำให้แล้ว
- [ ] **เทียบกับงบทดลอง** — ต้องขึ้นคำว่า **ตรงกัน** ทั้งลูกหนี้และเจ้าหนี้

### ถ้ายอดไม่ตรง

| ต่างเท่าไหร่ | มักเกิดจาก | ทำอย่างไร |
|---|---|---|
| ต่างเท่ากับใบใดใบหนึ่งพอดี | ใบนั้นถูกชำระหลังวันตัดยอด ระบบเดิมจึงรายงานว่าปิดแล้ว | เปิดรายงานอายุลูกหนี้ ณ วันตัดยอด หาใบนั้น แล้วเพิ่มเข้า `financii-import.json` เอง |
| ต่างเป็นยอดกลม ๆ | งบทดลองที่ใช้เป็นคนละวันกับ `--cutoff` | ดาวน์โหลดงบทดลองใหม่ให้ตรงวัน |
| ต่างเล็กน้อยระดับสตางค์ | ปัดเศษของระบบเดิม | ดู `errors.csv` ว่ามีใบที่ยอดไม่ลงตัวไหม |

**อย่านำเข้าทั้งที่ยอดยังไม่ตรง** — นำเข้าไปแล้วต้องกลับรายการทีละใบ เสียเวลากว่าเดิม

## ขั้นที่ 3 — เตรียมระบบใหม่

- [ ] เปิดเว็บ → เมนู **ระบบ → นำเข้าข้อมูลจากระบบเดิม**
- [ ] กด **เริ่มจากบริษัทเปล่า** กรอกชื่อบริษัท เลขประจำตัวผู้เสียภาษี ปีรอบบัญชี
- [ ] ยืนยันว่าป้ายส้ม "ข้อมูลตัวอย่าง" หายไปแล้ว

## ขั้นที่ 4 — นำเข้า

- [ ] ลากไฟล์ `financii-import.json` มาวางในหน้านำเข้าข้อมูล
- [ ] หน้าสรุปต้องขึ้น **ยอดคุมผ่านครบทุกข้อ**
- [ ] ดูตารางความครบถ้วนในหน้าสรุป เทียบกับที่เห็นตอนแปลง ต้องเป็นตัวเลขเดียวกัน

## ขั้นที่ 5 — ตรวจหลังนำเข้า

เทียบทีละคู่ ต้องตรงทุกข้อ

- [ ] **งบทดลอง** ในระบบใหม่ = งบทดลองจากระบบเดิม ณ วันตัดยอด
- [ ] **อายุลูกหนี้** ยอดรวม = รายงานอายุลูกหนี้จากระบบเดิม
- [ ] **อายุเจ้าหนี้** ยอดรวม = รายงานอายุเจ้าหนี้จากระบบเดิม
- [ ] **ทะเบียนสินค้า** ยอดมูลค่ารวม = บัญชีสินค้าคงเหลือในงบทดลอง
- [ ] **ทะเบียนพนักงาน** จำนวนคน = ที่มีอยู่จริง และทุกคนมีเงินเดือน
- [ ] **หน้าแดชบอร์ด** ตรวจยอดคุมอัตโนมัติต้องเขียวครบ 7 ข้อ

## สิ่งที่ระบบ**ไม่ได้**ย้ายมาให้ ต้องตั้งเอง

| เรื่อง | ทำอย่างไร |
|---|---|
| ประเภทเงินได้ของภาษีหัก ณ ที่จ่ายรายผู้ขาย | ตั้งในทะเบียนผู้ขาย เพราะเปอร์เซ็นต์อย่างเดียวบอกประเภทไม่ได้ |
| ค่าล่วงเวลาและกองทุนสำรองเลี้ยงชีพของพนักงาน | กรอกในทะเบียนพนักงานก่อนทำเงินเดือนงวดแรก |
| ทะเบียนทรัพย์สินและค่าเสื่อมสะสม | Open API ของ FlowAccount ไม่มีให้ ต้องกรอกเอง |
| งบประมาณและโครงการ | กรอกเอง |
| เอกสารที่ปิดแล้วก่อนวันตัดยอด | ไม่ยกมาโดยตั้งใจ ยอดรวมอยู่ในยอดยกมาแล้ว ถ้าต้องการดูย้อนหลังให้เปิดที่ระบบเดิม |

## หลังย้ายเสร็จ

- [ ] ในระบบเดิม ทำเครื่องหมายว่าเลิกใช้ตั้งแต่วันตัดยอด แต่ **อย่าปิดบัญชีทิ้ง**
      กฎหมายกำหนดให้เก็บเอกสารและบัญชีไว้อย่างน้อย 5 ปี
- [ ] เก็บ `financii-import.json` `errors.csv` `coverage.csv` และไฟล์งบทดลองไว้เป็นหลักฐานการย้าย
- [ ] เริ่มออกเอกสารในระบบใหม่ตั้งแต่วันถัดจากวันตัดยอด
