# ดุลย์ — ระบบบัญชีที่รันได้ทั้งระบบในไฟล์เดียว

เปิดไฟล์ `webapp/index.html` ด้วยเบราว์เซอร์ใดก็ได้ ไม่ต้องติดตั้ง ไม่ต้องมีเซิร์ฟเวอร์
ไม่ต้องต่ออินเทอร์เน็ต ระบบทั้งหมดทำงานอยู่ในไฟล์นั้นไฟล์เดียว และเก็บข้อมูล
ไว้ในเบราว์เซอร์ของเครื่องที่เปิด (localStorage) ไม่ส่งข้อมูลออกไปที่ใด

```
open webapp/index.html          # macOS
xdg-open webapp/index.html      # Linux
start webapp\index.html         # Windows
```

## หลักที่ยึดไว้ในโค้ด

- **ประตูเดียว** — ไม่มีทางเขียนลงบัญชีแยกประเภทได้นอกจากผ่าน `post()` ที่ตรวจ
  สมดุล งวดเปิด/ปิด บัญชีลงรายการได้ และคู่ค้าที่บังคับ ทุกครั้ง
- **แก้ไม่ได้** — ใบสำคัญที่ลงบัญชีแล้วแก้ไม่ได้ ต้องกลับรายการพร้อมเหตุผล
  ตาม พ.ร.บ.การบัญชี พ.ศ. 2543 มาตรา 20
- **เงินเป็นจำนวนเต็ม** — เก็บเป็นจำนวนเต็มสเกล 4 ตำแหน่ง ปัดครึ่งขึ้น ไม่ใช้
  ทศนิยมลอยตัวที่ใดเลย และปัด VAT ที่ระดับเอกสารไม่ใช่ระดับบรรทัด
- **อัตราภาษีเป็นข้อมูล** — ทุกอัตราเก็บพร้อมช่วงวันที่มีผลบังคับ ระบบเลือกตาม
  *วันที่ของเอกสาร* การออกเอกสารย้อนหลังจึงได้อัตราที่ถูกเสมอ

## ข้อมูลตัวอย่าง

บริษัทสมมุติที่มีรายการจริง 7 เดือน (ม.ค.–ก.ค. 2569): ใบกำกับภาษี 91 ฉบับ
ใบสำคัญ 374 ใบ รายได้สะสม 33.1 ล้านบาท กำไรสุทธิ 3.7 ล้านบาท
งวดมกราคม–มิถุนายนปิดบัญชีแล้ว **งวดกรกฎาคมเปิดค้างไว้** พร้อมงานที่ยังไม่ได้ทำ
4 อย่าง เพื่อให้ลองกดทำเองได้: ตั้งค่าเสื่อมราคา ทำเงินเดือน ยื่น ภ.พ.30
และกระทบยอดธนาคาร 3 รายการ

กดปุ่ม "ล้างข้อมูลและเริ่มใหม่" ในหน้า *เกี่ยวกับระบบนี้* เพื่อสร้างข้อมูลชุดใหม่

## พัฒนาต่อ

```bash
node webapp/test.js      # ทดสอบเครื่องบัญชี 55 ข้อ (ไม่ต้องมีเบราว์เซอร์)
node webapp/uitest.js    # ทดสอบหน้าเว็บจริงใน Chromium 69 ข้อ
node webapp/build.js     # รวม src/*.js กลับเป็น index.html ไฟล์เดียว
```

แก้โค้ดที่ `webapp/src/` แล้วสั่ง `node webapp/build.js` ทุกครั้ง —
`index.html` เป็นไฟล์ที่ถูกสร้างขึ้น ไม่ควรแก้ตรง ๆ

| ไฟล์ | หน้าที่ |
|---|---|
| `src/engine.js` | เงิน วันที่ ผังบัญชี งวด การลงบัญชี ยอดคงเหลือ งบการเงิน |
| `src/operations.js` | ธุรกรรมทางธุรกิจทั้งหมด — ขาย ซื้อ ภาษี ค่าเสื่อม เงินเดือน ปิดงวด |
| `src/seed.js` | ผังบัญชี ข้อมูลหลัก และตัวสร้างรายการตัวอย่างย้อนหลัง |
| `src/ui-core.js` | ส่วนประกอบหน้าจอ เมนู การเก็บข้อมูลในเครื่อง |
| `src/ui-screens.js` | 35 หน้าจอ |
| `src/ui-actions.js` | ฟอร์มสร้างเอกสารและตัวรับเหตุการณ์ทุกปุ่ม |
