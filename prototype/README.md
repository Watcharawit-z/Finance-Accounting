# ต้นแบบหน้าเว็บ DULY

`index.html` เป็นไฟล์เดียวจบ เปิดในเบราว์เซอร์ได้เลย ไม่ต้อง build อะไร
ประกอบด้วยหน้าเว็บการตลาด และตัวสำรวจหน้าจอแอป **43 หน้า** ครอบคลุมทุกโมดูล

## การแก้ไข

ห้ามแก้ `index.html` โดยตรง — ไฟล์นั้นถูกสร้างขึ้นมา

```bash
cd prototype/build
python3 build.py      # แปลงข้อมูลหน้าจอเป็นชิ้นส่วน HTML (parts.py)
python3 assemble.py   # ประกอบเป็น ../index.html
```

| ไฟล์ | หน้าที่ |
|------|---------|
| `build/screens_data.py` | ข้อมูลของทุกหน้าจอ (ชื่อ คอลัมน์ แถว หมายเหตุ) — แก้ที่นี่ |
| `build/build.py` | เรนเดอร์แต่ละหน้าจอเป็น HTML |
| `build/assemble.py` | CSS + โครงหน้าเว็บ + ประกอบไฟล์สุดท้าย |

## กติกาของข้อมูลตัวอย่าง

ตัวเลขทั้งหมดเป็นข้อมูลสมมติ แต่ **ต้องกระทบกันได้จริง** เพราะหน้าจอเหล่านี้ใช้สื่อสาร
กับนักบัญชี ถ้าตัวเลขไม่ลงตัวจะเสียความน่าเชื่อถือทันที ที่ตรวจไว้แล้ว:

- รวมสินทรัพย์ = รวมหนี้สินและส่วนของผู้ถือหุ้น (ทั้งปีปัจจุบันและปีก่อน)
- กำไรสะสมที่เพิ่มขึ้น = กำไรสุทธิในงบกำไรขาดทุน
- เงินสดปลายงวดในงบกระแสเงินสด = เงินสดในงบแสดงฐานะการเงิน
- ยอดเต็ม − ภาษีหัก ณ ที่จ่าย = ยอดจ่าย/รับสุทธิ ทุกแถว
- มูลค่าสินค้า + VAT = ยอดรวม ทุกใบกำกับภาษี
- ผลรวมทุกช่วงอายุหนี้ = ยอดลูกหนี้คงเหลือ
- ค่าเสื่อมทางบัญชี − ทางภาษี = ผลต่างที่นำไปกระทบยอด ภ.ง.ด.50
