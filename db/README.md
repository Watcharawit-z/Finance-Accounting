# ฐานข้อมูล DULY

## การรันครั้งแรก

```bash
createdb duly
for f in db/migrations/*.sql; do psql -d duly -v ON_ERROR_STOP=1 -f "$f"; done
psql -d duly -v ON_ERROR_STOP=1 -f db/seed/load_seed.sql
```

ไฟล์ migration ต้องรัน **ตามลำดับเลข** เพราะมี foreign key ข้ามไฟล์

## หลักการที่ยึดทั้งสคีมา

1. เงินทุกตัวเป็น `numeric(19,4)` — ห้าม `float`/`double`
2. ทุกตารางธุรกรรมมี `company_id` เพื่อใช้ RLS
3. เอกสารทุกใบเก็บ `*_snapshot` ของคู่ค้า ณ วันที่ออก (ข้อกำหนดกฎหมาย)
4. อัตราภาษี/เพดาน/ขั้นภาษี อยู่ในตารางที่มี `effective_from`–`effective_to` เสมอ
5. ตารางที่โตเร็ว (`journal_line`, `stock_move`, `audit_event`) ใช้ partition ตามวันที่
6. สถานะเอกสารใช้ enum เดียวกันทั้งระบบ (`doc_status`) เพื่อให้ UI/รายงานเขียนครั้งเดียว
