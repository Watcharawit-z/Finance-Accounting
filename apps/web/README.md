# DULY Web

React + Vite — เรียก API จริง ไม่มีข้อมูลจำลองฝังในหน้าจอ

```bash
npm install
npm run dev        # http://localhost:5173 (proxy /api ไปที่ http://127.0.0.1:3001)
npm run build
```

หน้าจอที่มี: ใบกำกับภาษี · สร้างใบกำกับภาษี · สมุดรายวัน · งบทดลอง · รายงานภาษีขาย · ตรวจยอดคุม

> นี่คือ **MVP ที่ต่อกับ API จริง** ไม่ใช่ต้นแบบการออกแบบ
> ต้นแบบหน้าตาเต็มรูปแบบ 43 หน้าอยู่ที่ [`prototype/`](../../prototype/)

## หลักการ

- **ตัวเลขภาษีมาจากเซิร์ฟเวอร์เสมอ** — ยอดที่คำนวณในเบราว์เซอร์เป็นแค่การแสดงผลล่วงหน้า
  ห้ามให้ฝั่ง client เป็นผู้ตัดสินตัวเลขที่จะลงบัญชี
- **ข้อความผิดพลาดแสดงทั้ง 3 ส่วน** — เกิดอะไรขึ้น (message) · จะแก้ยังไง (hint) · รหัสสำหรับแจ้งทีม (code)
- **ตัวเลขทุกตัวชิดขวาและใช้ tabular numerals** เพื่อให้หลักตรงกัน
- ใช้ชุดโทเค็นสีเดียวกับ design system ใน [docs/06](../../docs/06-design-system.md)
